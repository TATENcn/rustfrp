# 网络流量监控

守护进程在 Linux 上每 1 秒读取内核 TCP 诊断计数，按受管 frpc 进程的 socket 所有权、服务器地址和端口筛选连接。所有实例共享一次 TCP 快照，周期使用跳过错过时刻的定时器，慢采集不会并发堆积。无需第三方 FRP 服务器提供管理接口，也无需开启 frpc 管理端口。采集运行于应用层，不修改 FRP 转发逻辑。

## 三种统计口径

仪表盘网络流量卡片提供统计范围、服务器和明细筛选，并展示所选时间范围内的有效采样增量汇总及速率。页面每 5 秒刷新一次，后台每秒采样。

- **上游服务器**：可汇总当前环境的服务器配置或选择单个配置，统计 frpc 到服务器的 TCP 连接，包含控制和加密开销。
- **本地代理**：按服务器配置与代理 ID 分别计数，可跨服务器汇总同一代理，或筛选某台服务器下的代理。入站是 frpc 送达本地服务的字节，出站是从本地服务读取的字节。可能包含 frpc 健康探测流量。UDP/SUDP、插件代理不支持；同一个 frpc 下目标地址和端口重叠时无法归属，显示“共用目标”而非重复分摊。
- **系统网卡**：读取 `/proc/net/dev`，统计守护进程所在网络命名空间的所有应用流量，不受工作环境筛选限制。排除 `lo`，可按网卡筛选；容器中不一定代表物理宿主机。桥接、veth、隧道网卡汇总可能重复计算，查看外网流量应选择出口网卡。

三种口径不可相加。同一代理绑定不同服务器时，通过进程所有权区分；同一服务器配置内多个代理共用目标时不猜测归属。

## 支持范围

- 支持直接连接服务器的 TCP、WebSocket、WSS 传输。
- 暂不支持 KCP、QUIC、上游代理和非 Linux 平台。
- 统计包含控制连接、心跳、传输封装和加密开销，不等同于代理业务流量账单。
- 定时快照可能漏掉两次采样之间关闭的短连接及连接关闭前的最后增量。
- 需要系统允许读取对应进程的 `/proc` 信息及 `NETLINK_SOCK_DIAG`；容器、进程权限或安全策略可能限制采集。

## 计数与展示

首次观测作为基线，此后累积可观测字节增量。进程重启或所属环境改变时建立新的计数周期。仪表盘根据同一周期的相邻样本计算 B/s，并汇总当前环境各实例的收发速率。重启、计数回退、超过 15 秒的采样间隔不会产生虚假速率。

样本通过已有 `/api/v1/metrics/history` 返回，`source=linux_tcp`，`counter_epoch` 标识进程周期；`active_connections` 表示服务器传输 TCP socket 数，不是业务连接数。历史保存在有界内存缓冲区，守护进程重启后清空。服务器、本地代理、网卡分别最多保留 36,000 条、最近一小时的样本；多个对象共享各自类别的容量，对象数量较多时可用窗口会缩短。界面显示实际缓存起点，区间汇总只累计有效相邻样本的增量，采集缺口不会推算。暂不提供按日/月持久化账单。外部上报仍受支持，前端优先使用同一实例的本地采样，避免重复计数。

`proxy_traffic` 使用 `source=linux_local_tcp` 并携带 `proxy_id`；`host_traffic` 使用 `source=linux_interface` 并携带 `interface`。这些字段与 `traffic` 独立返回。`traffic_collection` 返回采集时间、整体状态、各实例状态、`proxies` 状态与 `host_state`。API 对流量和实例采集状态应用租户、环境和配置筛选。

## 排查

- “正在采集流量”：首个采样用于基线，下一次采样后显示速率。
- 无服务器 TCP 会话：检查代理分配页的运行状态、FRP 登录日志和服务器连接。
- 不支持的协议或上游代理：当前采集器无法测量，不以零流量代替。
- 系统计数或进程不可读：检查容器策略、`/proc` 可见性和运行账户。
- 已暂停：超过 15 秒未更新采集状态，检查守护进程日志和 API 连接。

## 回归验证

`cargo test -p rustfrp-daemon --lib --locked` 包含真实 TCP 字节读取、计数周期与租户隔离测试。前端包含速率计算单测及 Playwright 图表/异常状态测试。

可使用本地二进制运行独立的真实 FRP 集成测试：

```sh
python3 scripts/tests/traffic-smoke.py \
  --daemon target/debug/rustfrp-daemon \
  --frpc /path/to/frpc --frps /path/to/frps
```

脚本使用临时数据库、回环端口和配置，验证 1 MiB 回显传输的服务器和代理独立计数、约 1 秒采样周期、网卡采集、共用目标提示及重启周期，不修改项目的运行配置。
